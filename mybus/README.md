# MyBus.ge

ავტობუსებისა და მიკროავტობუსების ერთიანი პლატფორმა საქართველოსთვის, TNET-ის ეკოსისტემის სტილში (tkt.ge / mymarket.ge / myauto.ge).

მძღოლები აქვეყნებენ რეისებს (მარშრუტი, გასვლის დრო, ფასი, ავტობუსის ფოტო), მგზავრები კი პოულობენ რეისს, ჯავშნიან ადგილს და იხდიან ონლაინ ან მძღოლთან. მძღოლი ხედავს მგზავრების სრულ სიას: სახელი, გვარი, ტელეფონი, ელფოსტა, ადგილები, გადახდის სტატუსი.

## გაშვება

```bash
cd mybus
npm install
npm run dev        # http://localhost:3000
```

პირველ გაშვებაზე ავტომატურად იქმნება SQLite ბაზა (`data/mybus.db`) დემო მონაცემებით: 6 მძღოლი, 8 ავტობუსი და 100+ რეისი მომდევნო 7 დღეზე.

## ტექნოლოგიები

- **Next.js 16** (App Router, Server Components, Server Actions)
- **SQLite** (`node:sqlite`, ჩაშენებული, გარე სერვისების გარეშე)
- **Tailwind CSS v4**, ქართული ტიპოგრაფიკა (Noto Sans Georgian)
- საკუთარი auth: scrypt პაროლები + httpOnly cookie სესიები

## ფუნქციონალი

- ძებნა მიმართულებით და თარიღით, დალაგება დროით/ფასით
- რეისის გვერდი: ავტობუსის ფოტო, განრიგი, მძღოლის კონტაქტი, თავისუფალი ადგილები
- ჯავშანი 1-4 ადგილზე, გადახდა ონლაინ (სიმულაცია) ან ნაღდით მძღოლთან
- ელექტრონული ბილეთი ჯავშნის კოდით
- მძღოლის კაბინეტი: ავტობუსების დამატება (ფოტოს ატვირთვით), რეისების გამოქვეყნება/გაუქმება, მგზავრების მანიფესტი
- მგზავრის კაბინეტი: მოახლოებული მგზავრობები, ისტორია, ჯავშნის გაუქმება

> გადახდები დემო რეჟიმშია: რეალური payment provider (TBC/BOG) ინტეგრაცია განზრახ არ არის ჩართული.

## მძღოლის LIVE რეჟიმი

მარშრუტკის რეალობისთვის: მძღოლი LIVE ეკრანზე ითვლის ადგილზე ჩამსხდარ მგზავრებს ("+1 ჩაჯდა"), ონლაინ ჯავშნები კი იმავე მრიცხველზე ავტომატურად აისახება ხმოვანი სიგნალით. ონლაინ გაყიდვები ავტომატურად იხურება გასვლამდე 30 წუთით ადრე (ან ერთი ღილაკით), უფასო გაუქმება წყდება 1 საათით ადრე, არმოსულების ადგილები კი ერთი ღილაკით თავისუფლდება.

## WhatsApp ბოტი

ყოველი ონლაინ ჯავშანი და გაუქმება მძღოლს ავტომატურად ეგზავნება WhatsApp-ზე: მარშრუტი, დრო, მგზავრის სახელი, ტელეფონი, ადგილები, გადახდის სტატუსი და დარჩენილი ადგილები.

- **დემო რეჟიმი (default):** გასაღებების გარეშე შეტყობინებები ინახება და ჩანს მძღოლის კაბინეტში, "შეტყობინებები" ტაბზე, ზუსტად ისე, როგორც WhatsApp-ში მივიდოდა.
- **რეალური გაგზავნა:** [Meta WhatsApp Business Cloud API](https://developers.facebook.com/docs/whatsapp/cloud-api)-დან აიღე ტოკენი და ნომრის ID, ჩაწერე გარემოს ცვლადებში და ბოტი ავტომატურად აამუშავებს გაგზავნას:

```bash
WHATSAPP_TOKEN=<Meta access token>
WHATSAPP_PHONE_NUMBER_ID=<WhatsApp Business phone number ID>
```

- გარდა ბოტისა, მანიფესტში, LIVE ეკრანზე და ბილეთზე არის პირდაპირი WhatsApp ჩატის ღილაკები (wa.me), რომლებიც API-ის გარეშეც მუშაობს.
